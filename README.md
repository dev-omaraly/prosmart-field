# Pro Smart Field App

## التشغيل على GitHub
1. اعمل Repository جديد على GitHub وارفع كل ملفات المشروع (بما فيها فولدر .github).
2. من Settings > Pages اختار Source: GitHub Actions.
3. أي Push على main بيبني الموقع وينشره تلقائي.
4. للـ APK: من تبويب Actions اختار "Build Android APK" واضغط Run workflow، وبعد ما يخلص نزّل الملف من Artifacts (prosmart-apk).

## تشغيل محلي
npm install
npm run dev
